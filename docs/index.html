チューニング

「補正の強さ」は、再生数が少ない動画の率を全体平均に引き寄せる量です。0にすると生の率になり、少数再生の偶然の高評価が上位に来やすくなります。「検索時のバランス」は、雰囲気で探したときの並び順で、関連度と埋もれ度（総合スコア）をどの割合で混ぜるかです。100%にすると関連度だけで並びます。設定と検索語はURLに保存されるので、そのまま共有できます。

    このページのしくみ・推奨環境

    どこで何をしているか

    毎朝 6:37ごろGitHub上の自動処理（GitHub Actions）が、ニコニコ動画のスナップショット検索APIから投稿7日以内の候補を集め、タイトル・タグ・説明文をAIで数値（384個の数の並び）に変換して、このページに置きます。
    ページを開いたとき候補の一覧（約2.5MB）を読み込み、埋もれ度の計算・並び替え・絞り込みをあなたのブラウザの中で行います。
    雰囲気で探したときAIモデルとそのライブラリを初回だけダウンロードし、検索語の数値化と候補との比較をあなたの端末の中で計算します。検索語はどこにも送信されません。

    初回の検索で読み込むもの

    • AIモデル multilingual-e5-small（8bit量子化版）：Hugging Faceから 約120MB（実測値は検索の内訳に表示）
    • 計算ライブラリ（Transformers.js）：jsDelivrから
    • 候補の数値データ：約2MB

    2回目以降はブラウザに保存されたものを使うので、すぐに検索できます（ブラウザのデータを消すと再ダウンロードになります）。

    推奨環境

    • パソコンの最新版 Chrome / Edge を推奨。Safari・Firefoxの最新版でも動く見込みです
    • スマホでも動きますが、初回のダウンロードと計算に時間がかかります。Wi-Fiでの利用を推奨します
    • 費用はかかりません（サーバー側でAIを動かしていないため）

    「検索の内訳」「なぜこの順位？」の読み方

    • 関連度：検索語と動画（タイトル・タグ・説明文をまとめた文章）の、意味の近さ。−1〜1の値で、大きいほど近い
    • 埋もれ度：再生数のわりに、いいね・マイリスが平均の何倍ついているか
    • 合成スコア：関連度と埋もれ度は単位が違うので、それぞれを「平均0・ばらつき1」にそろえてから、設定した割合で足し合わせています
    • 効いた語句（参考）：タグやタイトルの語句を1つずつ検索語と比べた推定値です。実際の順位は文章全体で計算しているので、一致しないことがあります。説明文は公開していないため含まれません
