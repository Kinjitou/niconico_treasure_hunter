# 💎 埋もれた良作発掘くん

投稿から7日以内で、再生数のわりにいいね・マイリスが多いニコニコ動画を毎朝ピックアップする非公式ツール。

## しくみ

1. GitHub Actions が毎朝 6:37 JST に `fetch.py` を実行する
2. `fetch.py` が [スナップショット検索API v2](https://site.nicovideo.jp/search-api-docs/snapshot) から、投稿7日以内の候補を日別に取得する
3. 結果を `docs/data/latest.json`（公開ページ用）と `data/history/YYYY-MM-DD.json.gz`（履歴）に保存してコミットする
4. GitHub Pages が `docs/` を公開する。並び順やしきい値はページ上で調整できる

## チューニングの場所

| 何を変えたいか | 場所 |
|---|---|
| 候補プール（対象日数・動画種別・再生数レンジ・取得件数） | `config.toml` |
| 並び順・しきい値・補正の強さ・重み | 公開ページの「チューニング」（URLに保存される） |

### スコアの考え方

- いいね率・マイリス率は、再生数が少ないほど偶然に左右されるため、全体平均に「補正の強さ」分の再生数ぶん引き寄せてから比較する
  `補正いいね率 = (いいね数 + m × 全体平均いいね率) / (再生数 + m)`
- 総合スコア = 補正いいね率と補正マイリス率が、それぞれ全体平均の何倍かの加重平均

## 手動実行

Actions タブ → `daily-fetch` → Run workflow。`force` をオンにすると同じスナップショットでも取り直す。

ローカル実行：`python fetch.py --force`（Python 3.11以上、外部ライブラリ不要）

## 利用規約上の配慮

- 非営利。広告や収益化はしない
- 投稿者ID・チャンネルID・説明文・最新コメントは取得も保存もしない
- APIへのリクエストは、前回のレスポンス時間と同じだけ（最低1秒）間隔をあける
- 本ツールは個人が制作・運営する非公式ツールで、ニコニコ公式のサービスではない
